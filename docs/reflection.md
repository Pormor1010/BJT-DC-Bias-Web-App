## คำถามที่ต้องตอบ

1. **เหตุใดการเปิด `templates/index.html` ตรง ๆ จึงไม่เท่ากับการรัน Flask?**

   เพราะ `index.html` เป็น *template* ของ Jinja2 ไม่ใช่หน้าเว็บสำเร็จรูป ข้างในยังมีตัวแปรเช่น `{{ form.vcc }}`, `{{ result.vce }}`, `{% if error %}` ที่ยังไม่ถูกแทนค่า การเปิดผ่าน `file://` เบราว์เซอร์จะอ่านไฟล์อย่างเดียว ไม่มี Python รันอยู่ จึงไม่มีใครคำนวณค่า DC Bias และเมื่อกดปุ่มเบราว์เซอร์ก็พยายามส่งฟอร์มไปยัง `file:///.../calculate` ซึ่งไม่มีเซิร์ฟเวอร์รับ request (ขึ้นข้อผิดพลาด) ส่วน `/static/style.css` ก็ชี้ไม่ถูกที่ ทำให้สีและหน้าตาหายไป การรัน Flask จึงจำเป็น — Flask เป็นเซิร์ฟเวอร์ที่รับ HTTP request, เรียกฟังก์ชันคำนวณใน `dc_bias.py`, แล้วส่ง HTML ที่แทนค่าครบแล้วกลับไปให้เบราว์เซอร์

2. **ฟอร์มส่งข้อมูลไป Python อย่างไร?**

   เส้นทางคือ: ผู้ใช้กดปุ่มใน `<form method="post" action="/calculate">` → เบราว์เซอร์ห่อค่า 7 ช่องเป็น HTTP POST (`application/x-www-form-urlencoded`) ส่งไปที่ `http://127.0.0.1:5000/calculate` → Flask จับคู่กับ route `@app.post("/calculate")` ใน `app.py` → เรียก `calculate()` → `_parse()` อ่าน `request.form` แปลงเป็นตัวเลขและคูณ 1000 สำหรับช่องตัวต้านทาน (kΩ → Ω) → ส่งค่า SI ทั้งหมดเข้า `solve(**params)` ใน `dc_bias.py` → ผลลัพธ์ถูกแปลงหน่วยโดย `_display()` → `render_template("index.html", result=..., error=..., warnings=...)` แทนค่าลงใน HTML แล้วส่งกลับให้เบราว์เซอร์วาดหน้าใหม่

3. **แก้สมการใน `dc_bias.py` แล้วต้องแก้ HTML หรือไม่? เพราะอะไร?**

   ไม่ต้อง ถ้าแก้เฉพาะ *ตัวเลข* ที่ได้จากสมการ เพราะ `index.html` ไม่มีสมการฟิสิกส์และไม่มีการคำนวณอยู่ในตัวเลย มันทำหน้าที่แค่แสดงผลจาก dict ที่ Flask ส่งมา (แสดง `{{ result.vce }}` เป็นต้น) ตามกติกาห้าม hardcode ผลลัพธ์หรือใส่สมการใน template การแก้สมการจึงจบที่ `dc_bias.py` ไฟล์เดียว และเทสต์ใน `tests/test_dc_bias.py` จะตรวจค่าอ้างอิงให้อัตโนมัติ

   ข้อยกเว้นคือถ้าแก้จนชื่อคีย์หรือหน่วยเปลี่ยน (เช่นเพิ่ม `vcb` หรือเปลี่ยน `ic` จากแอมแปร์เป็นมิลลิแอมแปร์ใน `solve()`) ก็ต้องแก้ทั้ง `_display()` ใน `app.py` และแถวใน template ให้ตรงกัน ไม่งั้นจะได้ค่าว่างหรือหน่วยผิด

4. **ทำไมผลใน Region ที่แบบจำลองใช้ไม่ได้จึงต้องมี Warning?**

   เพราะสมการทั้งหมดตั้งอยู่บนสมมติฐานว่า BJT ทำงานใน Forward-Active จริง (รอยต่อ Base–Emitter นำ, Collector–Base reverse bias) ถ้าค่าการคำนวณออกมาอยู่นอกช่วงนั้น ตัวเลขยังออกมาได้สวย ๆ แต่อาจเป็นไปไม่ได้ทางกายภาพ เช่น ตั้ง `RC = 47 kΩ` ค่า IC ยังขึ้นว่า 1.230 mA ดูปกติ แต่ VCE ที่คำนวณได้ติดลบ (−47.045 V) ซึ่งเป็นไปไม่ได้ — จริง ๆ ทรานซิสเตอร์อิ่มตัว (VCE ≈ 0.2 V) ไม่ได้ขยายสัญญาณตามสมการ ถ้าเอาเลขนี้ไปออกแบบต่อจะเข้าใจผิดว่าวงจรทำงานได้เต็มช่วง อีกกรณีคือ `R2 = 1 kΩ` ทำให้ VTH ต่ำกว่า VBE วงจรอยู่ใน Cutoff กระแสเป็นศูนย์ ไม่มี bias ให้ใช้งาน โปรแกรมจึงต้องเตือนแทนที่จะปล่อยให้เชื่อตัวเลขนั้น
